# 북드릴 Chrome 확장

책덕후를 위한 비공식 플러그인입니다. RIDI에 로그인된 Chrome 세션으로 내 서재를 분석하고, 전체 페이지형 서지 관리 화면과 RIDI 페이지 인핸서, 스토어 전체에 적용되는 소장 표시·숨김·이어보기를 제공합니다.

RIDI와 외부 서점의 로그인 쿠키·비밀번호를 복사하거나 Vercel 서버로 전송하지 않습니다.

## 설치

1. `ridi-driller-extension.zip`의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 개발자 모드를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
5. 압축을 푼 폴더에서 `manifest.json`이 있는 폴더를 선택합니다.

업데이트된 ZIP으로 교체한 경우 기존 확장의 새로고침 버튼을 누르고 열려 있던 RIDI 탭도 새로고침합니다.

확장 관리 화면에 표시되는 현재 버전은 `0.7.6`입니다.

## 처음 설치했을 때

설치하면 RIDI 구매 목록이 열리고 `서재 분석이 필요합니다` 안내 창이 뜹니다.

`서재 분석 시작`을 누르면 그 창 안에서 진척률(퍼센트·단계·처리 건수)을 보여 주고, 끝나면 닫을 수 있습니다.

`나중에`나 Esc로 닫으면 다시 뜨지 않습니다. 분석은 확장 아이콘이나 서재 화면의 `서재 분석` 버튼으로 언제든 시작할 수 있습니다.

로그인돼 있지 않으면 로그인 링크를 안내합니다.

## RIDI 서재 분석

1. [RIDI](https://ridibooks.com/account/login)에 로그인합니다.
2. Chrome 도구 모음에서 북드릴 아이콘을 누릅니다.
3. 로그인 상태가 확인되면 `서재 분석`을 누릅니다.
4. 분석이 끝나면 `서지 관리 열기`를 누릅니다.

분석은 서재 규모에 따라 수 분이 걸릴 수 있습니다.

서지 관리 화면에는 전체 서지·미구매 신권·아직 안 읽은 작품·완독·관심 작품·구매 작가의 다른 작품·독서노트·통합 서점 탭이 있습니다.

작품명·작가·출판사·메모 검색과 서점·소장 상태·독서 상태·미구매 권 필터를 함께 적용할 수 있습니다.

### 검색 문법

서재·신간의 인라인 목록과 서지 관리 화면이 같은 문법을 씁니다.

| 입력 | 뜻 |
|---|---|
| `원피스 오다` | 두 낱말을 모두 포함 (순서 무관, 제목·작가·출판사 어디에 있든) |
| `원피스 \| 나루토` | 둘 중 하나. `OR`로 써도 됩니다 |
| `원피스 -합본` | `합본`이 들어간 작품 제외 |
| `"오다 에이치로"` | 따옴표 안을 한 덩어리로 |
| `작가:오다` | 그 항목에서만 찾기. `제목:` · `작가:` · `출판사:` · `메모:`(서지 관리) |

부분 일치이며 대소문자·전각/반각·띄어쓰기를 무시합니다(`원 피스`로 `원피스`를 찾음).

검색 범위 선택(통합·작품명·작가·출판사)은 항목을 적지 않은 낱말에만 적용됩니다.

인라인 목록은 검색어를 어떻게 이해했는지 `검색 조건` 줄에 조건별로 보여 주고, 조건을 하나씩 눌러 지울 수 있습니다.

결과가 없으면 걸린 조건과 문법 안내, `조건 모두 지우기`를 함께 보여 줍니다.

한 번에 해석하는 범위는 낱말 12개, `|` 묶음 4개까지입니다.

RIDI 본문 인라인 목록은 원본 페이지 번호와 별개로 전체 로컬 색인을 24·48·96개 단위로 나눕니다.

작품별 로컬 메모는 `chrome.storage.local`에만 저장됩니다.

## RIDI 페이지 인핸서

| RIDI 화면 | 주소 | 추가 기능 |
|---|---|---|
| 구매 목록 | [ridibooks.com/library/books](https://ridibooks.com/library/books) | 전체 구매 작품 인라인 목록, 페이지네이션, 소장·읽기·신권·관심 필터 |
| 내 책장 | [ridibooks.com/library/shelves](https://ridibooks.com/library/shelves) 및 개별 책장 | 전체 책장·책장별 전체 작품 인라인 목록과 페이지네이션 |
| 관심 작품 | [ridibooks.com/library/serial-preferences](https://ridibooks.com/library/serial-preferences) | 전체 관심 작품 인라인 목록, 관심·새 이야기 필터 |
| 만화 신작 | [ridibooks.com/comics/new-releases](https://ridibooks.com/comics/new-releases?tab=CATEGORY_COMIC_ALL) | 11개 장르 전체 신간 인라인 목록, 장르·소장·미구매·신권·내 작가·관심 필터 |
| 작품 상세 | `ridibooks.com/books/{id}` | 마지막 열람·독서 상태·소장 권수, 다른 서점 구매 기록·수집한 독서노트 연결, 책 읽기·구매·독서노트·서지 관리 동선 |

도구와 결과는 화면 위에 떠 있는 카드나 호버 레이어가 아니라 RIDI 본문 흐름에 들어갑니다.

목록은 언제나 하나만 보입니다. 평소에는 RIDI 원본 목록에 배지만 덧씌우고 그 위에 검색·필터 한 줄만 둡니다.

검색어를 넣거나 필터를 누르거나 `전체 N개 한 번에 보기`를 누르면, 원본 목록과 쪽 번호가 접히고 전체 색인의 결과 목록으로 바뀝니다.

`RIDI 원본 목록으로`나 `필터 초기화`를 누르면 원본 목록으로 돌아갑니다.

결과는 위쪽 도구 줄 안이 아니라 RIDI 원본 목록이 있던 바로 그 자리에, 원본과 같은 칸 크기·표지 크기·간격으로 그립니다. 필터를 누르면 같은 격자 안에서 표지가 바뀌는 것처럼 보입니다.

서재 분석이 돌아가는 동안에는 제목 옆에 `서재 분석 42% · 3/6단계 · 읽기 843/1686` 같은 문구와 진척률 막대가 나옵니다. `서재 다시 분석`을 누른 즉시 표시되고, 분석 도중에 화면을 새로 열어도 이어서 표시됩니다. 스토어 화면의 막대에도 같은 퍼센트가 표시됩니다.

결과 목록은 RIDI 원본과 같은 표지 격자입니다. 칸 크기와 간격은 그 화면의 원본 표지에서 읽어 옵니다.

한 가지 정보는 한 곳에만 적습니다.

| 자리 | 내용 |
|---|---|
| 표지 위 배지 (최대 2개) | 읽기 상태, 관심·새 이야기 |
| 표지 아래쪽 알약 | 소장 권수. 다 가졌으면 `총 9권`, 일부면 `2/64권 · 미구매 62` |
| 표지 밑 | 제목, 작가, 날짜(정렬 기준에 맞는 구매일·열람일·출간일)와 별점 |

그 화면의 모든 작품에 해당하는 상태는 표시하지 않습니다. 구매 목록·책장에는 `소장`이, 관심 작품에는 `관심`이 붙지 않고, 눌러도 달라지지 않는 필터(전부 해당하는 조건)도 숨깁니다.

서재 탭 줄의 `구매 작가의 다른 작품`은 새 창을 열지 않고 그 화면 안에서 같은 격자로 목록을 보여 줍니다. 별점 드롭다운과 검색을 쓸 수 있습니다.

이 탭의 목록에도 구매 목록과 같은 필터(유형·카테고리·태그·별점 상태·성인·완결·잡지 제외·별점)와 정렬이 붙습니다. 검색 결과에 값이 있는 것만 표시되며, 서재를 다시 분석한 뒤부터 채워집니다.

이 탭은 RIDI 탭을 그대로 복제해 만들고, 고르면 RIDI 탭과 같은 밑줄·굵은 글씨로 표시됩니다. 그동안 구매 목록 전용 도구 줄(`모든 책 검색`·편집)은 가려 두고, 다른 탭을 누르면 원래대로 돌아옵니다.

RIDI 원본 목록은 한 쪽(48권)씩만 내려오므로 전체를 다시 정렬할 수 없습니다. 정렬 기준이나 방향을 바꾸면 모든 쪽을 합친 전체 색인으로 바뀌어 그 기준으로 정렬됩니다.

만화 신작에서는 별점을 0.1점 단위 드롭다운으로 거를 수 있습니다. 별점이 없는 작품은 거르지 않습니다.

별점이 비어 있는 이유는 세 가지로 구분합니다.

| 상태 | 뜻 | 표지 아래 문구 |
|---|---|---|
| 별점 없음 | 작품은 확인됐지만 아직 평가가 없음 | `별점 없음` |
| 불러오지 못함 | 요청이 실패했거나 검색 결과에 작품이 없어 확인하지 못함 | `별점 불러오지 못함` · `별점 확인 불가` |
| 불러온 적 없음 | 한 번도 확인하지 않음 (예전 버전으로 분석한 데이터 등) | `별점 미확인` |

`별점 상태` 드롭다운으로 상태별로 모아 볼 수 있습니다. 별점 슬라이더는 별점이 있는 작품만 거릅니다.

만화 신작의 `별점 새로고침`은 신간 목록 전체를 다시 받지 않고 별점 칸만 고칩니다. 불러오지 못한 것과 불러온 적 없는 것은 모두, 별점 없음은 최근 60일 안에 나온 것만 다시 확인합니다. 갓 나온 신간은 별점이 없다가 며칠 뒤에 붙기 때문입니다.

서재 작품은 다음 `서재 다시 분석` 때 요청이 실패한 것부터 다시 확인하고, 별점 없음과 검색에 없던 것은 14일 뒤에 다시 확인합니다.

글꼴은 RIDI 화면의 것을 물려받고 색과 선도 RIDI의 것을 따릅니다.

`미구매 또는 미독`은 두 상태의 합집합이고, 그 밖의 복수 상태 버튼은 교집합으로 적용됩니다.

인라인 목록은 유형(만화·소설 등)·완결 여부로 거르고, 미구매 권수·보유 권수로 정렬하며 방향을 바꿀 수 있습니다.

`CSV 저장`은 현재 검색·필터 조건에 맞는 전체 목록을 파일로 내려받습니다.

신간 목록의 `구매 작가의 다른 작품`과 `내 서재 신권`은 작가 ID와 시리즈 ID로 연결하므로, 분석이 미리 검색한 상위 작가 40명만이 아니라 구매한 모든 작가의 신간이 잡힙니다.

구매 목록·책장의 표지에는 `소장` 배지를 달지 않고 미구매·읽기 상태만 두 개까지 표시합니다.

작품 상세의 `다른 서점` 줄은 ISBN이 일치한 구매 기록과 제목만 일치한 기록을 구분해 표시합니다. 제목 일치는 판·권이 다를 수 있습니다.

기본 상태에서는 RIDI 원본 카드·쪽 번호를 그대로 둡니다. 숨김·접기는 사용자가 켰을 때만 적용되고, 원본 노드를 지우지 않고 가리기만 합니다. 구매 버튼은 건드리지 않습니다.

구매 목록과 관심 작품은 인증 API의 마지막 페이지까지, 신간은 장르별 `next_page`가 끝날 때까지, 책장은 count 기준 마지막 오프셋까지 수집합니다.

전체 신간·책장 캐시는 30분 동안 재사용하고, 저장된 결과를 먼저 보여준 뒤 만료 데이터만 갱신합니다.

책 ID가 없는 라이브러리 카드는 제목을 보조 키로 사용하므로 동명 작품이나 제목 변경이 있으면 오탐·누락될 수 있습니다.

### 구매 목록: RIDI 목록 자체를 거르기

구매 목록에서 검색·필터·정렬을 쓰면 확장이 목록을 따로 그리지 않고, RIDI 서재가 받는 목록 데이터를 걸러진 결과로 바꿔 줍니다.

그래서 카드, `총 N권`, 쪽 번호, 선택·편집이 모두 RIDI 원본 그대로이고, 쪽 번호도 걸러진 건수에 맞게 줄어듭니다.

| 항목 | 동작 |
|---|---|
| 바꾸는 요청 | 구매 목록(`/items/main/`)과 전체 건수(`/items/main/count/`)를 읽는 두 요청의 응답 본문만 |
| 건드리지 않는 것 | 구매·삭제·책장 변경 등 그 밖의 모든 요청, RIDI 자체 필터(대여·카테고리)가 걸린 요청 |
| 실패했을 때 | RIDI 원본 응답이 그대로 쓰여 서재는 평소처럼 보임 |
| 필터를 바꿀 때 | RIDI 목록이 다시 받도록 쪽 번호를 잠깐 바꿨다 되돌림. 그동안 목록을 투명하게 했다가 새 결과와 배지가 다 준비되면 다시 보임(약 1초) |
| 쪽당 개수 | RIDI의 48권 그대로 |

필터가 켜져 있는 동안에는 RIDI의 정렬 메뉴 대신 확장의 정렬이 적용됩니다.

이 방식은 서재 분석이 목록 항목을 저장해 둔 뒤에만 동작합니다. `0.6.0` 이전에 분석한 데이터라면 `서재 다시 분석`을 한 번 눌러야 하고, 그 전까지는 확장이 같은 자리에 결과를 직접 그립니다.

책장·관심 작품·만화 신작·작가 탭은 데이터 구조가 달라 확장이 원본 자리에 직접 그리는 방식을 유지합니다.

### 필터와 정렬

| 필터 | 내용 |
|---|---|
| 유형 · 카테고리 | 목록에 실제로 있는 값만, 많은 순으로 |
| 태그 | 여러 개를 고를 수 있음. 고른 태그 중 하나라도 있는 작품을 표시 |
| 별점 상태 | 별점 있음 · 별점 없음 · 불러오지 못함 · 불러온 적 없음 |
| 성인 | 전체 · 성인만 · 성인 제외 |
| 완결 | 전체 · 완결만 · 완결 제외 |
| 잡지 제외 | 잡지가 있을 때만 표시 |
| 별점 | 0.1점 단위 슬라이더. 별점이 확인되지 않은 작품은 거르지 않음 |

정렬은 기본·최신 출간·최근 구매·최근 열람·작품명·미구매 권수·보유 권수·별점·최근 읽은 권·추천순(해당 값이 있는 목록에서만)입니다.

드롭다운은 모두 같은 모양입니다. 레이블이 항상 보이고, 기본값이 아닌 값을 고르면 파란 테두리·굵은 글씨로 표시되며, 키보드 포커스와 비활성 상태가 구분됩니다. 강조색은 작은 글씨에서도 대비 4.5:1을 넘는 `#0b6bcb`를 씁니다.

확장이 직접 그리는 목록은 `쪽 번호` · `더 보기` · `무한 스크롤` 중에서 넘기는 방식을 고를 수 있습니다.

### 별점과 태그

책 정보 API에는 별점과 태그가 없습니다. 서재 분석의 `별점·태그 확인` 단계가 작품 제목으로 검색해 책 ID나 시리즈 ID가 일치하는 결과의 값만 저장하고(`ridi_ratings`) 서지에 합칩니다.

이미 찾은 값은 다음 분석에서 다시 찾지 않습니다. 못 찾은 작품은 14일 뒤에 다시 찾습니다.

처음 분석할 때는 작품 수만큼 검색이 더 나가므로 시간이 더 걸립니다.

서재 표지에는 저장된 별점이 `★ 4.8`로 표시됩니다.

## RIDI 스토어 인핸서

검색 결과·카테고리·베스트셀러·신간·장르 홈·작품 상세의 추천 목록 등 `ridibooks.com` 스토어 화면 전체에서 동작합니다.

서재·계정·주문·결제·뷰어 화면에는 주입하지 않습니다.

화면 위쪽 본문 흐름에 `북드릴` 한 줄이 생기고, 그 화면에 보이는 작품 수와 소장·숨김 수를 보여 줍니다.

작품 상세에는 `작품 서지` 패널만 두고 이 줄을 따로 얹지 않습니다. 상세의 추천 목록에서는 숨김 대상도 없애지 않고 흐리게만 합니다.

만화 신작에서는 전체 신간 검색 줄 바로 위에 붙어 한 덩어리로 보입니다.

### 소장 표시

서재 분석 결과를 스토어 카드에 연결해 표지에 배지를 답니다.

| 배지 | 뜻 |
|---|---|
| `소장` · `소장 9권` | 내 서재에 있는 작품(전부 소장) |
| `소장 2/8` | 소장 중인 시리즈에 아직 사지 않은 권이 있음 (소장 권수 / 발매 권수) |
| `안 읽음` · `읽는 중` · `보유분 완독` · `완독` | 연결된 서재 기록의 읽기 상태. RIDI는 시리즈별로 가장 최근에 연 권만 알려 주므로 "몇 권까지 읽음"은 표시하지 않음 |
| `관심` · `새 이야기` | 관심 작품과 그 새 이야기 |
| `구매 작가` | 내 서재에 작품이 있는 작가의 다른 작품. 작가 ID로 맞추며 번역가·삽화가는 제외 |
| `다른 판 소장` | 제목은 같지만 시리즈가 다른 판(e북과 연재 등)을 소장 중 |

연결 순서는 책 ID, 시리즈 ID, 정규화한 제목입니다.

제목만 같고 시리즈 ID가 다르면 소장으로 보지 않고 `다른 판 소장`으로만 알립니다.

카드의 시리즈 ID를 알 수 없을 때는 제목 일치를 소장 시리즈로 표시하므로 동명 작품에서 오탐이 날 수 있습니다.

### 숨기기와 흐리게 하기

| 설정 | 동작 |
|---|---|
| 소장 `표시 / 흐리게 / 숨김` | 전부 소장한 작품에 적용. 미구매 권이 남은 시리즈는 숨기지 않음 |
| 완독 `표시 / 흐리게 / 숨김` | 끝까지 읽은 작품에 적용 |
| 별점 | 슬라이더로 정한 별점 미만인 작품을 숨김. 0.1점 단위 |
| 골라 보기 | `구매 작가의 다른 작품` · `내 시리즈의 미구매 권` · `미구매` · `관심` 중 켠 것에 하나라도 맞는 작품만 남김 |
| 성인 숨김 | 성인 작품을 숨김 |
| 평가 수 | 평가가 입력한 수보다 적은 작품을 숨김 |
| 차단어 | 제목·작가·출판사에 낱말이 들어 있으면 숨김 |
| 숨김 목록 | 표지에 마우스를 올려 `숨김`을 누른 작품. 같은 시리즈의 다른 권도 함께 숨김 |

별점·평가 수·성인 여부를 확인하지 못한 작품은 걸러 내지 않습니다.

`숨긴 작품 보기`를 켜면 숨겨진 카드가 점선 테두리로 잠시 다시 보입니다.

`설정`에서 숨김 목록의 작품을 `복원`할 수 있고, `인핸서 사용`을 끄면 모든 표시가 사라집니다.

작품 상세 화면에서는 그 작품 자신의 표지와 권 목록을 숨기지 않습니다.

### 강조

막대의 `강조` 줄에서 켠 조건에 맞는 작품의 표지 안쪽에 그라데이션 테두리를 두릅니다. 가리지 않고 눈에 띄게만 합니다.

| 강조 | 색 | 대상 |
|---|---|---|
| 내 시리즈의 미구매 권 | 파랑 → 청록 | 소장 중인 시리즈에 아직 사지 않은 권이 있는 작품. 서재 분석 뒤에 시리즈가 더 길어진 경우도 포함 |
| 구매 작가의 다른 작품 | 보라 → 분홍 | 내 서재에 작품이 있는 작가의 다른 작품 |
| 관심 | 진분홍 → 노랑 | 관심 작품 |

기본으로 앞의 두 가지가 켜져 있습니다. 한 작품이 여러 조건에 맞으면 위 순서로 하나만 표시합니다.

신간 화면에서 소장 중인 시리즈의 새 권은 `소장 9/10`처럼 지금 권수로 표시되고, `소장 숨김`을 켜도 가려지지 않습니다.

RIDI 카드가 별점을 보여 주지 않는 화면(신간 등)에서는 표지에 `★ 4.8`을 적습니다. 그 화면을 주소로 직접 열었을 때의 데이터에 별점이 들어 있는 작품만 표시됩니다.

별점 기준은 막대의 슬라이더(0.1점 단위)로 정합니다.

### 이어보기

쪽 번호가 있는 목록(검색 결과·카테고리 등)에는 원본 목록 끝에 `N쪽 이어 보기` 버튼이 붙습니다.

누르면 다음 쪽의 작품이 원본 목록 바로 뒤에 같은 모양으로 이어집니다. 표지 크기·위치와 글꼴·색은 그 화면의 RIDI 카드에서 읽어 옵니다.

이어 붙인 작품에도 숨김 설정, 골라 보기, 소장 배지가 그대로 적용됩니다.

이어 붙인 줄에는 다음 쪽 데이터에 들어 있는 순위 번호, 줄거리, 대여가·소장가(권당·전권), 할인율과 RIDI의 할인 배지를 원본 줄과 같은 자리에 표시합니다.

`열 때 합쳐 보기`를 `2쪽씩`–`5쪽씩`으로 두면, 목록을 열 때마다 다음 쪽들을 미리 불러와 처음부터 한 화면에 합쳐 보여 줍니다.

`스크롤하면 자동으로`를 켜면 끝에 닿을 때 다음 쪽을 불러오며, 한 번에 최대 10쪽에서 멈춥니다.

쪽 사이에는 0.45초 간격을 두고, 한 화면에서 최대 60쪽까지 불러옵니다.

### 저장 위치

스토어 설정(`ridi_store_prefs`)과 숨김 목록(`ridi_ignored_books`)은 `chrome.storage.local`에만 저장합니다.

## 독서노트

수집한 본문과 날짜는 서지 관리의 `독서노트` 탭과 메모 검색에서 확인할 수 있습니다.

RIDI 공식 안내상 PDF는 독서노트를 지원하지 않고 일부 PC 뷰어 형식은 서버 동기화되지 않으므로 확장이 모든 로컬 기록을 복구할 수는 없습니다.

## 외부 서점 구매 기록

지원 대상은 알라딘·YES24·교보문고·영풍문고입니다.

1. 해당 서점에 로그인합니다.
2. 주문·구매내역 페이지를 엽니다.
3. 북드릴 확장 아이콘을 누릅니다.
4. `{서점명} 구매 기록 가져오기`를 누릅니다.
5. 페이지를 넘겼다면 각 페이지에서 다시 가져옵니다.
6. `서지 관리 열기`의 `통합 서점` 탭에서 결과를 확인합니다.

확장은 일반 상품·추천 페이지를 구매내역으로 판별하지 않으며, 현재 화면에 보이는 상품만 가져옵니다.

전자책·종이책은 ISBN을 우선하고 제목과 대표 작가를 보조 키로 합치지만 합본·개정판·동명이인에서는 수동 확인이 필요합니다.

외부 서점 커넥터는 비공개 구매 화면의 DOM에 의존하는 베타 기능이며 네 서점의 로그인 실화면 검증은 아직 완료되지 않았습니다.

## 인증 동작

- `ridi-at`이 유효하면 현재 브라우저 쿠키로 RIDI 라이브러리 API를 호출합니다.
- 라이브러리 API가 401을 반환하면 공식 `POST account.ridibooks.com/ridi/token`을 호출하고 원요청을 한 번 재시도합니다.
- 갱신에는 브라우저의 `ridi-rt`가 자동 사용되지만 확장 저장소나 화면에는 토큰 값을 기록하지 않습니다.
- 403은 인증 만료와 구분하고 Cloudflare 오류로 표시합니다.
- 관심 작품은 읽기 전용 GraphQL `query`로 조회하며 관심 등록·해제 `mutation`은 실행하지 않습니다.
- 외부 서점은 사용자가 확장 팝업을 연 현재 탭의 `activeTab` 권한만 사용합니다.
- 스토어 이어보기는 사용자가 보고 있는 목록의 다음 쪽(`?page=N`)을 그 탭의 세션으로 요청하고 응답의 목록 데이터만 읽습니다.
- 스토어 카드의 시리즈·성인 여부는 공개 `book-api`로 한 번에 최대 100권씩 조회하며, 서재 분석 결과가 있거나 `성인 숨김`을 켠 경우에만 요청합니다.

## 오류 해결

### RIDI 로그인 안 됨

RIDI 로그인 페이지에서 로그인한 뒤 확장 팝업을 다시 엽니다.

### Cloudflare 403

[RIDI 서재](https://ridibooks.com/library)를 직접 열어 정상 표시되는지 확인한 뒤 확장에서 다시 분석합니다.

브라우저 자체에서도 챌린지가 보이면 해당 확인을 먼저 완료해야 합니다.

### 배지나 필터가 안 보임

확장 관리 화면에서 버전이 `0.7.6`인지 확인합니다.

확장의 새로고침 버튼을 누른 뒤 RIDI 탭도 새로고침하고 `서재 분석`을 다시 실행합니다.

### 스토어에서 작품이 사라져 보임

화면 위 `북드릴` 막대의 숨김 수와 사유를 확인하고 `숨긴 작품 보기`를 켭니다.

`설정`의 `설정 초기화`는 숨김 조건을 모두 기본값으로 되돌리며, 숨김 목록은 각 작품의 `복원`으로 비웁니다.

### 이어보기가 보이지 않음

쪽 번호가 없는 화면(장르 홈, 베스트셀러 등)에는 이어보기가 붙지 않습니다.

### 외부 서점에서 0개를 가져옴

주문·구매내역 페이지인지 확인하고, 목록이 화면에 로드된 뒤 다시 실행합니다.

서점이 DOM을 변경하면 커넥터 업데이트가 필요할 수 있습니다.

## 데이터 범위

RIDI는 시리즈별로 가장 최근에 연 권 하나만 제공하므로 표시되는 최근 읽은 권은 최고 도달 권과 다를 수 있습니다.

확장은 확인할 수 없는 읽기 기록을 임의로 보정하지 않습니다.

분석·서지·메모·독서노트·외부 구매 기록은 `chrome.storage.local`에 저장하며 외부 서버로 전송하지 않습니다.

세부 구조와 검증 경계는 [로컬 서지 관리와 서점 통합 구조](../docs/local-bibliography-architecture-2026-10-24.md)에 기록돼 있습니다.

RIDI 인증 근거는 [인증/API 분석 문서](../docs/ridi-auth-api-2026-10-24.md)에 기록돼 있습니다.

페이지 인핸서의 설계와 검증 범위는 [RIDI 페이지 인핸서 분석 문서](../docs/ridi-page-enhancer-2026-10-24.md)에 기록돼 있습니다.

화면별로 무엇이 들어가는지와 화면 간 차이는 [화면별 주입 기능](../docs/injection-matrix.md)에 정리돼 있습니다.

스토어 인핸서의 설계와 검증 범위는 [RIDI 스토어 인핸서 문서](../docs/ridi-store-enhancer-2026-11-21.md)에 기록돼 있습니다.
