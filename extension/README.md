# 리디 드릴러 Chrome 확장

RIDI에 로그인된 Chrome 세션으로 내 서재를 분석하고, 전체 페이지형 서지 관리 화면과 RIDI 페이지 인핸서를 제공합니다.

RIDI와 외부 서점의 로그인 쿠키·비밀번호를 복사하거나 Vercel 서버로 전송하지 않습니다.

## 설치

1. `ridi-driller-extension.zip`의 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions`를 입력합니다.
3. 오른쪽 위의 개발자 모드를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 누릅니다.
5. 압축을 푼 폴더에서 `manifest.json`이 있는 폴더를 선택합니다.

업데이트된 ZIP으로 교체한 경우 기존 확장의 새로고침 버튼을 누르고 열려 있던 RIDI 탭도 새로고침합니다.

확장 관리 화면에 표시되는 현재 버전은 `0.4.0`입니다.

## RIDI 서재 분석

1. [RIDI](https://ridibooks.com/account/login)에 로그인합니다.
2. Chrome 도구 모음에서 리디 드릴러 아이콘을 누릅니다.
3. 로그인 상태가 확인되면 `서재 분석`을 누릅니다.
4. 분석이 끝나면 `서지 관리 열기`를 누릅니다.

분석은 서재 규모에 따라 수 분이 걸릴 수 있습니다.

서지 관리 화면에는 전체 서지·미구매 신권·아직 안 읽은 작품·완독·관심 작품·구매 작가의 다른 작품·독서노트·통합 서점 탭이 있습니다.

작품명·작가·출판사·메모 검색과 서점·소장 상태·독서 상태·미구매 권 필터를 함께 적용할 수 있습니다.

작품별 로컬 메모는 `chrome.storage.local`에만 저장됩니다.

## RIDI 페이지 인핸서

| RIDI 화면 | 주소 | 추가 기능 |
|---|---|---|
| 구매 목록 | [ridibooks.com/library/books](https://ridibooks.com/library/books) | 소장·읽기·신권·관심 배지, 제목·작가 검색, 복수 상태 필터 |
| 내 책장 | [ridibooks.com/library/shelves](https://ridibooks.com/library/shelves) 및 개별 책장 | 소장·읽기·신권·관심 배지와 필터 |
| 관심 작품 | [ridibooks.com/library/serial-preferences](https://ridibooks.com/library/serial-preferences) | 관심·새 이야기 배지와 필터 |
| 만화 신작 | [ridibooks.com/comics/new-releases](https://ridibooks.com/comics/new-releases?tab=CATEGORY_COMIC_ALL) | 소장·미구매·신권·내 작가·관심 배지와 필터 |
| 작품 상세 | `ridibooks.com/books/{id}` | 마지막 열람·독서 상태·소장 권수, 책 읽기·구매·독서노트·서지 관리 동선 |

도구 영역은 화면 위에 떠 있는 카드가 아니라 RIDI 본문 흐름에 들어갑니다.

`미구매 또는 미독`은 두 상태의 합집합이고, 그 밖의 복수 상태 버튼은 교집합으로 적용됩니다.

RIDI 원본 카드와 구매 버튼은 교체하지 않으며 필터 초기화 시 숨겼던 원본 카드를 모두 복구합니다.

책 ID가 없는 라이브러리 카드는 제목을 보조 키로 사용하므로 동명 작품이나 제목 변경이 있으면 오탐·누락될 수 있습니다.

## 독서노트

[RIDI 독서노트](https://ridibooks.com/reading-note/timeline)를 열면 현재 화면에 표시된 형광펜·메모·책갈피를 로컬 저장소에 중복 없이 합칩니다.

수집한 본문과 날짜는 서지 관리의 `독서노트` 탭과 메모 검색에서 확인할 수 있습니다.

RIDI 공식 안내상 PDF는 독서노트를 지원하지 않고 일부 PC 뷰어 형식은 서버 동기화되지 않으므로 확장이 모든 로컬 기록을 복구할 수는 없습니다.

- [RIDI 독서노트 사용 방법](https://ridihelp.ridibooks.com/support/solutions/articles/154000207703)
- [작품 삭제 시 독서노트 동기화 여부](https://ridihelp.ridibooks.com/support/solutions/articles/154000207704-%EC%9E%91%ED%92%88-%EC%82%AD%EC%A0%9C-%EC%8B%9C-%EB%8F%85%EC%84%9C%EB%85%B8%ED%8A%B8-%EB%8F%99%EA%B8%B0%ED%99%94-%EC%97%AC%EB%B6%80)

## 외부 서점 구매 기록

지원 대상은 알라딘·YES24·교보문고·영풍문고입니다.

1. 해당 서점에 로그인합니다.
2. 주문·구매내역 페이지를 엽니다.
3. 리디 드릴러 확장 아이콘을 누릅니다.
4. `{서점명} 구매 기록 가져오기`를 누릅니다.
5. 페이지를 넘겼다면 각 페이지에서 다시 가져옵니다.
6. `서지 관리 열기`의 `통합 서점` 탭에서 결과를 확인합니다.

확장은 일반 상품·추천 페이지를 구매내역으로 판별하지 않으며, 현재 화면에 보이는 상품만 가져옵니다.

전자책·종이책은 ISBN을 우선하고 제목과 대표 작가를 보조 키로 합치지만 합본·개정판·동명이인에서는 수동 확인이 필요합니다.

외부 서점 커넥터는 비공개 구매 화면의 DOM에 의존하는 베타 기능이며 네 서점의 로그인 실화면 검증은 아직 완료되지 않았습니다.

## 인증 동작

- `ridi-at`이 유효하면 현재 브라우저 쿠키로 RIDI 라이브러리 API를 호출합니다.
- 라이브러리 API가 401을 반환하면 공식 `POST account.ridibooks.com/ridi/token`을 호출하고 원요청을 한 번 재시도합니다.
- 갱신에는 브라우저의 `ridi-rt`가 자동 사용되지만 확장 저장소나 화면에는 토큰 값을 기록하지 않습니다.
- 403은 인증 만료와 구분하고 Cloudflare 오류로 표시합니다.
- 관심 작품은 읽기 전용 GraphQL `query`로 조회하며 관심 등록·해제 `mutation`은 실행하지 않습니다.
- 외부 서점은 사용자가 확장 팝업을 연 현재 탭의 `activeTab` 권한만 사용합니다.

## 오류 해결

### RIDI 로그인 안 됨

RIDI 로그인 페이지에서 로그인한 뒤 확장 팝업을 다시 엽니다.

### Cloudflare 403

[RIDI 서재](https://ridibooks.com/library)를 직접 열어 정상 표시되는지 확인한 뒤 확장에서 다시 분석합니다.

브라우저 자체에서도 챌린지가 보이면 해당 확인을 먼저 완료해야 합니다.

### 배지나 필터가 안 보임

확장 관리 화면에서 버전이 `0.4.0`인지 확인합니다.

확장의 새로고침 버튼을 누른 뒤 RIDI 탭도 새로고침하고 `서재 분석`을 다시 실행합니다.

### 외부 서점에서 0개를 가져옴

주문·구매내역 페이지인지 확인하고, 목록이 화면에 로드된 뒤 다시 실행합니다.

서점이 DOM을 변경하면 커넥터 업데이트가 필요할 수 있습니다.

## 데이터 범위

RIDI는 시리즈별로 가장 최근에 연 권 하나만 제공하므로 표시되는 최근 읽은 권은 최고 도달 권과 다를 수 있습니다.

확장은 확인할 수 없는 읽기 기록을 임의로 보정하지 않습니다.

분석·서지·메모·독서노트·외부 구매 기록은 `chrome.storage.local`에 저장하며 외부 서버로 전송하지 않습니다.

세부 구조와 검증 경계는 [로컬 서지 관리와 서점 통합 구조](../docs/local-bibliography-architecture-2026-10-24.md)에 기록돼 있습니다.

RIDI 인증 근거는 [인증/API 분석 문서](../docs/ridi-auth-api-2026-10-24.md)에 기록돼 있습니다.

페이지 인핸서의 설계와 검증 범위는 [RIDI 페이지 인핸서 분석 문서](../docs/ridi-page-enhancer-2026-10-24.md)에 기록돼 있습니다.
