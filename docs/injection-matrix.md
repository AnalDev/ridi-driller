# 화면별 주입 기능과 통일 결과 (확장 0.7.6)

북드릴이 RIDI의 각 화면에 무엇을 넣는지 정리하고, 화면마다 다르게 구현돼 있던 것을 어떻게 맞췄는지 적는다.

## 어떤 스크립트가 어디에 들어가는가

| 스크립트 | 들어가는 곳 | 세계 |
|---|---|---|
| `library-bridge.js` | `ridibooks.com/library*`, `library.ridibooks.com` | 페이지 (앱보다 먼저) |
| `page-enhancer.js` | 서재(구매 목록·책장·관심), 만화 신작, 작품 상세 | 확장 |
| `store-enhancer.js` | `ridibooks.com` 전체에서 서재·계정·주문·결제·뷰어·독서노트를 뺀 곳 | 확장 |
| `reading-notes-content.js` | 독서노트 | 확장 |
| `onboarding.js` | 위 두 인핸서가 불러 씀 | 확장 |

만화 신작과 작품 상세에는 `page-enhancer.js`와 `store-enhancer.js`가 함께 들어간다.

## 화면별 기능

"원본"은 RIDI가 그린 카드·목록, "확장 목록"은 북드릴이 원본 자리에 직접 그린 격자를 뜻한다.

| 기능 | 구매 목록 | 책장 · 관심 | 작가 탭 | 만화 신작 | 검색 · 카테고리 등 | 작품 상세 |
|---|---|---|---|---|---|---|
| 도구 줄 | 서재 줄 | 서재 줄 | 서재 줄 | 스토어 줄 + 서재 줄(붙어 있음) | 스토어 줄 | 작품 서지 패널 |

## 다르게 구현돼 있던 것과 맞춘 방법

| 항목 | 이전 | 지금 |
|---|---|---|
| 읽기 상태 판정 | 서재 표지와 확장 목록은 분석의 "안 읽은 작품" 목록에 있으면 `안 읽음`. 이 목록에는 보유분을 다 읽고 미구매 권만 남은 시리즈도 들어 있어 `안 읽음`으로 잘못 표시됨. 스토어 표지만 서재 기록의 읽기 상태를 씀 | 세 곳 모두 `readingBadge()` 하나를 씀: `안 읽음` · `읽는 중` · `보유분 완독` · `완독` |
| 같은 개념의 이름 | `아직 안 읽음`/`안 읽음`, `내 서재 신권`/`미보유 신권`/`미구매 권`/`구매한 시리즈의 새 권·미구매 권`, `구매 작가`/`구매 작가의 다른 작품` | `안 읽음`, 서재에서는 `미구매 권 있음`, 남의 작품이 섞인 화면에서는 `내 시리즈의 미구매 권`, 필터·강조·탭은 `구매 작가의 다른 작품`(표지 배지는 자리 때문에 `구매 작가`) |
| 서재 표지의 미구매 표시 | `미구매 권` (권수 없음) | `미구매 6권` (서재 기록의 권수) |
| 숨김 목록·차단어 | 스토어의 원본 카드에만 적용. 신간 확장 목록과 작가 탭에는 숨긴 작품이 그대로 나옴 | 신간 확장 목록과 작가 탭에서도 빠짐 |
| 강조 | 스토어의 원본 카드와 이어 붙인 줄에만 | 신간 확장 목록의 칸에도 같은 색 테두리 |
| 신간의 "내 시리즈 신권" 필터 | 분석이 만든 미구매 목록에 제목이 있을 때만 | 스토어 표지와 같은 연결 규칙(책 ID → 시리즈 ID). 소장 시리즈에 미구매 권이 있으면 걸림 |
| 신간 확장 목록의 표지 배지 | 상태 이름만 | 연결된 서재 기록의 읽기 상태와 `소장/발매` 권수 |
| 별점 기준 입력 | 서재 줄은 슬라이더, 스토어 줄은 드롭다운 | 모두 슬라이더(0.1점 단위) |
| 드롭다운 모양 | 화면마다 제각각, 레이블 없음 | `dropdown()` 하나로 통일 |
| 신간 API의 별점 | 단일 점수로 읽어 항상 값 없음 | 별점별 건수의 가중 평균 |

## 일부러 다르게 둔 것

| 항목 | 이유 |
|---|---|
| 구매 목록만 RIDI 원본 목록 자체를 거름 | 서재 앱이 받는 목록 응답 형식을 알고 원본 항목을 저장해 둔 화면이 구매 목록뿐이다. 책장·관심·신간은 데이터 구조가 달라 확장이 원본 자리에 직접 그린다 |
| 서재 화면에는 강조·숨김 목록이 없음 | 전부 내가 산 작품이라 "구매 작가의 다른 작품"이나 "숨길 작품"이 해당하지 않는다 |
| 스토어 화면에는 낱말 검색·유형·카테고리 필터가 없음 | RIDI 자체 검색과 카테고리가 그 일을 한다. 확장은 소장 여부처럼 RIDI가 모르는 조건만 더한다 |
| 작품 상세에는 도구 줄이 없고 숨김이 흐리게로 바뀜 | 조작할 줄이 없는 화면에서 추천 작품을 말없이 없애지 않기 위해서다 |
| 표지 별점 표시 조건 | 서재 표지에는 RIDI가 별점을 보여 주지 않아 항상 적고, 스토어 표지에는 RIDI 카드에 별점이 없을 때만 적는다(중복 방지) |
| 작가 탭의 범위 | 분석이 구매 권수 상위 작가 40명을 검색해 둔 결과다. 스토어·신간의 `구매 작가의 다른 작품`은 모든 구매 작가 기준이다 |

## 확인 범위

이번 통일 작업은 단위 테스트(242개), ESLint, TypeScript 검사로 확인했다. 실화면에서는 통일 전 단계에서 만화 신작의 강조·슬라이더를 확인했고, 통일 뒤의 서재 표지 문구·신간 확장 목록의 강조·숨김 목록 적용은 실화면에서 보지 못했다.

## 0.7.5에서 더 맞춘 것

| 항목 | 내용 |
|---|---|
| 작가 탭의 필터 | 구매 목록과 같은 필터를 쓴다. 분석이 검색 결과에서 유형·카테고리·성인(`age_limit`)·완결(`is_series_complete`)·별점 건수를 함께 저장한다. 값이 없는 칸은 비워 두고 필터에서 단정하지 않는다 |
| 태그 | 한 개만 고르던 드롭다운을 여러 개 고르는 드롭다운으로 바꿨다. 같은 항목 안의 선택은 OR이다 |
| 별점이 비어 있는 이유 | `별점 없음` · `불러오지 못함` · `불러온 적 없음`을 서재·신간·작가 탭·스토어 데이터에서 같은 이름(`ratingStatus`)으로 구분한다 |
| 신간 별점 새로고침 | 다시 확인할 대상을 상태로 좁힌다. 신간 3,379권 중 1,802권은 원래 평가가 없어, "별점 없는 것 전부"를 다시 확인하면 전체 새로고침과 시간이 같았다(2.7초 대 2.9초, 실측). 그래서 `별점 없음`은 최근 60일 안에 나온 것만 다시 본다 |

실화면(최근 구매 300작품 중 80작품의 별점 조회)에서 태그 두 개를 고르면 둘 중 하나라도 있는 80작품으로 걸러지고, `별점 상태`에 `별점 있음 80 · 불러온 적 없음 220`이 나오는 것을 확인했다. 작가 탭의 새 필터와 신간 별점 새로고침의 60일 기준은 실화면에서 보지 못했다.

## 0.7.6: 그리는 순서와 깜빡임

필터를 걸 때 화면이 깜빡이고 요소가 지워졌다 생기는 원인은 넷이었다.

| 원인 | 고친 방법 |
|---|---|
| RIDI 가 카드를 새로 그리면 0.15초 뒤에야 배지·숨김을 적용 → 숨길 카드가 먼저 보였다 사라지고 목록이 출렁임 | `MutationObserver` 콜백 안에서 바로 적용한다. 이 콜백은 DOM 이 바뀐 직후, 브라우저가 화면에 칠하기 전에 불린다 |
| 확장 목록과 검색 조건 칩을 내용이 같아도 매번 지우고 다시 만듦 | 보여 줄 내용의 지문(`renderKey`)이 같으면 건너뛴다 |
| 구매 목록을 다시 받는 동안 2쪽 내용·빈 목록·배지 없는 카드가 그대로 보임. RIDI 가 목록 노드를 통째로 새로 만들어 목록에 단 표시가 같이 사라졌음 | 문서 뿌리에 상태를 달고 "도구 줄 뒤의 모든 것"을 투명하게 한다. 높이는 붙잡아 둔다. RIDI 가 0.25초 동안 조용해지면 배지를 단 뒤 다시 보인다 |
| 결과 영역·도구 줄이 "원본 목록 바로 앞"이 아니면 다시 끼워 넣음 → 사이에 다른 요소가 있으면 끝없이 반복 | "앞에 있기만 하면 됨"으로 바꿨다 |

같이 고친 것:

- 조건이 없을 때 `필터 초기화`·정렬 방향·`CSV 저장`을 없애지 않고 비활성으로 둔다. 필터를 걸어도 도구 줄 높이가 변하지 않는다(실측 171px → 171px).
- 다시 그리기 예약을 요청마다 미루지 않는다. 미루면 DOM 이 쉬지 않고 바뀌는 화면에서는 한 번도 그려지지 않는다.

구매 목록에서 필터를 눌렀을 때의 실측 순서: 0.10초 목록 투명(카드 0) → 0.25초 새 카드 48개와 배지 적용(아직 투명) → 0.66초 나타나기 시작 → 0.89초 완료. 덜 그려진 상태가 보인 순간은 없었고 아래 내용의 위치도 변하지 않았다.

### 강조 테두리

카드 전체에 두르던 단색 테두리를 표지 안쪽의 그라데이션 고리로 바꿨다. 카드끼리는 간격이 거의 없어 카드 전체에 두르면 옆 테두리와 붙었다. 표지 안쪽에 그리면 표지 사이의 간격만큼 떨어진다.

| 강조 | 색 |
|---|---|
| 내 시리즈의 미구매 권 | 파랑 → 청록 |
| 구매 작가의 다른 작품 | 보라 → 분홍 |
| 관심 | 진분홍 → 노랑 |

확인한 환경에는 이전 빌드의 확장이 함께 떠 있어, 두 확장이 서로의 요소를 옮기는 변화가 계속 섞였다. 새 빌드 하나만 떠 있을 때의 화면은 보지 못했다.
